# Roup-HTML

A static HTML/CSS/JS site with a simple PHP script (`checkPasskey.php`) for passkey checking.

## Setup
1. Upload files to your Hostinger hosting account.
2. Run `composer install` if you add PHP dependencies.
3. Access `index.html` in your browser.

## Dependencies
- PHP ^8.1
- Font Awesome (via CDN)
